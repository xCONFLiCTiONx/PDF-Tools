# Local PDF Tools

**Local PDF Tools** is a privacy-first Chrome extension that allows you to merge, split, and manage PDF files directly in your browser. All processing happens locally on your machine—your files are never uploaded to any server.

## 🚀 Overview

Manage your documents with confidence. This extension provides a robust suite of PDF manipulation tools that operate entirely within the client-side environment, ensuring your sensitive data never leaves your device.

## ✨ Key Features

- **Multi-Format Support**: Process PDF, PNG, JPG, and WebP files in a single unified workspace.
- **Visual Page Management**:
  - **Drag & Drop Reordering**: Intuitively rearrange pages with a 2D spatial grid.
  - **Individual Page Rotation**: Correct orientation issues with 90-degree increment rotations.
  - **Selective Page Deletion**: Prune unnecessary pages before final generation.
- **Powerful Export Options**:
  - **Merge & Export**: Combine multiple documents and images into a single, optimized PDF.
  - **Export as Images**: Convert every page in your workspace into high-quality PNG files.
  - **PDF Compression**: Optional object stream compression to minimize file sizes.
- **Live Previews**: Zoom into specific pages or preview the entire merged document before saving.
- **Privacy Guaranteed**: Works entirely offline with no external data transmission.

## 🛠️ Installation (Developer Mode)

1. Download or clone this repository.
2. Navigate to `chrome://extensions/` in Google Chrome.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the project root folder.

## 📖 How to Use

1. **Load Files**: Drag and drop PDF or Image files onto the dashboard.
2. **Organize**: Use the visual grid to drag and reorder thumbnails. Use hover actions to rotate or delete.
3. **Configure**: Set your filename and toggle compression in the control panel.
4. **Preview**: Click "Preview PDF" to verify your changes.
5. **Generate**: Click "Merge & Export" or "Export All as Images" to save your work.
