# PDF-Tools Privacy Policy

**Effective Date:** August 5, 2026

PDF-Tools is a privacy-first browser extension for managing PDF files.

## 1. Local Processing
- **Client-Side Only:** All PDF manipulations (merging, splitting, etc.) are performed locally within your browser using JavaScript. Your PDF files are never uploaded to a server.

## 2. Permissions
The extension requires access to files only when you explicitly select them for processing. No data is collected or shared with third parties.
